# 🌑 Shadow Realm

**Shadow Realm** is a text-based RPG adventure built with Python. Create your character, choose a class, develop your stats, gain experience, and fight mysterious creatures.

The project is currently in early development. The goal is to gradually expand it into a full RPG with a world to explore, quests, enemies, abilities, and eventually a 2D graphical interface.

## 🎮 Features

### Character Creation
- Choose your character's name.
- Select one of three available classes.
- Each class has unique starting statistics and an ability.

### Character Classes

| Class | Health | Attack | Defense | Ability |
|---|---:|---:|---:|---|
| Warrior | 120 | 15 | 10 | Shield Wall |
| Mage | 80 | 22 | 3 | Fireball |
| Rogue | 90 | 18 | 4 | Shadow Strike |

### Progression System
- Gain experience points.
- Level up your character.
- Increase attack and maximum health.
- Restore health when leveling up.
- Experience requirements increase with each level.

### Combat System
- Fight enemies in turn-based battles.
- Attack enemies and receive counterattacks.
- Check your character's statistics.
- Escape from battles.

## 🛠️ Technologies

- **Python 3**
- Built-in Python features:
  - Dictionaries
  - Functions
  - Loops
  - Conditional statements
  - User input

No external libraries are currently required.

## 🚀 Getting Started

### Requirements
- Python 3.10 or newer
- Visual Studio Code or another Python-compatible editor

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/shadow-realm.git
   ```

2. Open the project folder:

   ```bash
   cd shadow-realm
   ```

3. Run the game:

   ```bash
   python main.py
   ```
